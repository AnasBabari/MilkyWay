# Selected experiment evidence

Start with [the experiment narrative](../docs/EXPERIMENTS.md). This directory keeps
a small set of machine-readable reports: M18 qualification and policy ablation,
Silky-Snow keep/revert decisions, a later speed validation, Search V2, null-move
and the final documented time-manager diagnostic.

These are historical records. Candidate paths, absolute host paths and partial-run
fields inside JSON describe the original experiment, not runnable current defaults.
Restore the [archive snapshot](../docs/BUILD_PROVENANCE.md) to reproduce those
campaigns. The full raw tree is preserved there, including rejected source,
training artifacts that were tracked, game records and intermediate archives.
