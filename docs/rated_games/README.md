# Selected rated-game forensics

This directory preserves analysis of two rated losses, against LarpMaxx in round
20 and Neomatica in round 25. It is not a complete corpus of all 43 final losses.
The reports are dated historical investigations, with build-specific replay and
clock observations. Some raw PGN/JSONL inputs were ignored by the original repo;
those files are not promised in this checkout.

Critical FENs remain embedded in `tests/test_rated_regressions.py`. The reports
explain why those tests exist. The full tracked forensic state is preserved in the
competition archive; see [build provenance](../BUILD_PROVENANCE.md).
