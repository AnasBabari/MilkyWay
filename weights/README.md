# Root runtime model

`milkyway_policy.onnx` (5,268,829 bytes) is the team-trained model selected by
`root_policy.DEFAULT_ONNX_PATH`. The root engine enables it by default when ONNX
Runtime can load it; set `MILKYWAY_ROOT_POLICY=0` for the classical ordering path.

SHA-256: `4d93818689914495e41c1241adab1529509beacabfc2e653ff629a9a2f41e9aa`.
Historical policy ablation did not establish a gain. This model is not the compact
value residual inside the last documented TM ZIP. Experimental flagship variants
and their external data remain in the archive tag, not the portfolio working tree.
